# Core data model

All durable formats are versioned. Session-internal models may evolve but RPC and
report formats follow compatibility rules.

## Session

```text
id                 random UUID generated by daemon
owner_uid          authenticated Unix peer owner
role               workstation|downloader|scanner|exporter
phase              state-machine phase
image_identity     OCI digest + manifest digest
resources          vCPU, RAM, root and scratch limits
policy             immutable policy snapshot
created_at         monotonic/wall timestamp pair
runtime_path       derived path under /run/private-vm
```

No user-provided value becomes part of a host path.

## Image identity

An executable image is identified by:

```text
registry repository manifest_digest layer_digest role bundle architecture
source_repository source_commit workflow source_ref
guest_api_major/minor nixos_version sbom_digest
```

A tag is never an execution identity.

## Device enrollment

```text
enrollment_id
vendor_id
product_id
serial
physical_port_path
interface triples
reported capacity
enrollment timestamp
optional human label
```

All fields except human label participate in matching. Serial-less devices are
not eligible in v1.

## Transfer

A transfer is a single logical file with declared size, MIME, SHA-256 and bounded
ordered chunks. It is never a general filesystem tunnel.

## Scan report

The report records scanner image, definitions, input identity, findings,
transformations, output identities and final result. `complete=false` or a
missing field cannot approve a transfer.

## Workspace state

- `CLEAN`: no files in Export.
- `READY`: every current file version has an export receipt.
- `UNEXPORTED`: at least one file has no receipt.
- `CHANGED`: at least one file changed after its receipt.
- `UNREACHABLE`: transport status, not a persisted guest state.

## Sensitive versus non-sensitive fields

Sensitive by default:

- magnet URI and info hashes;
- torrent display/file names;
- VPN configuration and endpoint association;
- user file names and hashes;
- browsing state;
- scan input names;
- USB encryption passphrases.

Permitted lifecycle metadata, when explicitly enabled:

- session ID;
- role;
- coarse start/end timestamps;
- terminal phase;
- error code without private arguments.
